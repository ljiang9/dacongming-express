# 大聪明高速返程博弈模拟器 🚗💨

国庆 10 天假期的返程博弈:你以为提前走、凌晨走就能避堵?
不好意思——**高速上挤满了聪明人**。

## 梗来源声明

灵感来自 2026-10-06 真实热梗"**大聪明又失算了**":有人提前返程想避开拥堵,
结果反而被堵死在高速上,网友辣评"大聪明"。本项目为善意玩梗的原创模拟小游戏,
不针对任何真实个人,祝大家一路平安。

## 玩法

你扮演一名返程车主:

1. 在 10 月 **4 / 5 / 6 / 7** 四天里选一天出发
2. 再选时段:**凌晨 / 上午 / 下午 / 深夜**
3. 60 位 AI NPC 车主各有"聪明度"(0–100):聪明度越高,越倾向"提前走避堵"
4. 拥堵模型:`车流 = 基础返程流 + 同路 NPC 数 × 2 + 随机事故系数`,再乘时段系数
   - 聪明人扎堆选 4/5 号凌晨 → 越想避堵越堵,完美复刻"大聪明又失算了"
5. 高速名场面随机事件:服务区野餐泡茶、下车遛狗拉伸、新能源充电取号 99 号等 5 小时、错过出口倒车被罚、后备箱特产大甩卖
6. 结算:按你的耗时 vs NPC 中位数,打出"大聪明等级":
   青铜大聪明 → 黄金大聪明 → 钻石大聪明 → **大聪明之王**,另有隐藏结局"反套路大师"

## 运行

```bash
python3 -m dacongming_express                 # 交互模式(需终端)
python3 -m dacongming_express --auto --games 10 --seed 42        # 自动演示 10 局
python3 -m dacongming_express --auto --games 1 --seed 7 --verbose # 单局战报
python3 -m dacongming_express --auto --games 20 --npc 120        # 120 个 NPC 更挤
```

纯 Python 标准库(`argparse`/`random`/`sys`/`time`),Python 3.10+。

## 诚实局限

- 拥堵参数(基础流/时段系数/事故上限)为拍脑袋设定的抽象单位,不是真实路况数据
- NPC 决策是固定权重随机,没有学习、没有路况广播、没有"看到导航红了改道"
- 事件纯概率触发,与真实事故率无关;文案多玩几局会眼熟
- 文本界面,无图形/存档/联网;`select` 倒计时等高级交互一概没有
